# Import Data Using Transform Maps - Spreadsheet

## Project Description
This project demonstrates how to import spreadsheet data into ServiceNow
using Import Sets and Transform Maps.

## Technologies Used
- ServiceNow
- Import Sets
- Transform Maps
- Excel / Spreadsheet
- Field Maps
- Coalesce

## Project Components
1. Data Source
2. Import Set Table
3. Transform Map
4. Field Maps
5. Coalesce
6. Target Table
7. Transform
8. Import/Transform Logs

## Project Flow
Excel Spreadsheet
       ↓
Data Source
       ↓
Import Set Table
       ↓
Transform Map
       ↓
Field Maps
       ↓
Target Table
